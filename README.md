# Nepolia

**Nepolia** a social media platform that allows users post something, follow other user, interact in real-time through messaging, etc.

🌐 [Live Demo](https://nepolia.vercel.app)


## ✨ Key Features
- 🔐 User authentication
- 🗨️ Real-time chat
- 👤 Edit user profiles
- 📸 Post with Image upload
- 👍 Like Post
- 🗨️ Comment and Reply
- 🔎 Search user
